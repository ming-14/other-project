# JavaScript Formatter

在线 JS 代码美化、格式化工具。粘贴你的杂乱 JS 代码，一键格式化，支持多种自定义选项。

## 功能特性

- **缩进方式**：Tab 缩进、2 空格、4 空格、8 空格
- **自动换行**：不换行 / 超过 80、120、160 字符换行
- **大括号风格**：换行（collapse）或不换行（expand）
- **括号间距**：条件语句空格、函数名与括号之间空格、匿名函数括号前空格、括号内空格
- **链式方法换行**：每个方法独立一行
- **末尾空行**：可选在代码末尾添加空行
- 基于 CodeMirror 编辑器，体验流畅

## 使用方法

1. 浏览器打开 `index.html`
2. 将 JS 代码粘贴到编辑框中
3. 根据需要调整格式化选项
4. 点击「格式化 JS 代码」按钮
