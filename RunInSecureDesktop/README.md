# RunInSecureDesktop
在安全桌面显示窗口  
  
## 实现方式 | 运行流程
复制 winlogon.exe 进程的令牌，在安全桌面创建进程  
  
开始 Start  
│  
├─1. 启用权限阶段  
│   ├─启用 SE_DEBUG_NAME 权限  
│   └─启用 SE_TCB_NAME 权限  
│   │  
│   └─失败 → 输出错误信息 → 退出程序  
│  
├─2. 参数处理阶段  
│   ├─设置目标进程为 "winlogon.exe"  
│   └─设置程序路径  
│  
├─3. 主循环监控阶段  
│   │  
│   ├─3.1 检查安全桌面是否激活  
│   │   ├─是 → 继续执行  
│   │   └─否 → 等待1秒 → 重新检查  
│   │  
│   ├─3.2 获取winlogon.exe进程列表  
│   │   └─跳过会话0的系统进程  
│   │  
│   ├─3.3 遍历每个符合条件的 winlogon 进程  
│   │   ├─打开进程句柄  
│   │   ├─打开进程令牌  
│   │   ├─复制令牌  
│   │   └─在安全桌面启动辅助程序  
│   │       │  
│   │       ├─成功 → 输出成功信息 → 暂停 → 退出程序  
│   │       └─失败 → 继续处理下一个进程  
│   │  
│   └─3.4 所有进程处理完毕 → 等待1秒 → 重新开始循环  
│  
└─程序结束
