# 大Phrase 2: 全屏TUI游戏体验

## 状态: 进行中

## 目标

将推箱子游戏从简陋的字符输出升级为全屏TUI体验，地图居中、双宽渲染、信息面板、边框装饰，达到正式可玩品质。

## 核心问题

当前渲染引擎的问题：
1. 地图太小，1字符=1格，在80x24终端里地图只有几行
2. 没有全屏布局，地图紧贴左上角
3. 信息（步数、关卡）和地图混在一起
4. 没有边框和视觉层次
5. 没有获取终端实际尺寸

## 设计方向

### 全屏布局（120x40 为例）

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│  SOKOBAN                                                            Level 1 / 3       │
├──────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                      │
│                              ┌─────────────────┐                                    │
│                              │  ████           │                                    │
│                              │  █ .█           │                                    │
│                              │  █@$ █          │                                    │
│                              │  █   █          │                                    │
│                              │  └───█          │                                    │
│                              │    ███          │                                    │
│                              └─────────────────┘                                    │
│                                                                                      │
├──────────────────────────────────────────────────────────────────────────────────────┤
│  Steps: 0  Pushes: 0    │  ↑↓←→/WASD: Move  R: Restart  Z: Undo  Q: Quit         │
└──────────────────────────────────────────────────────────────────────────────────────┘
```

### 关键设计决策

1. **双宽渲染**：每个地图格子用2个终端列宽渲染（全角字符），地图视觉上更方正
2. **地图居中**：根据终端尺寸计算地图显示区域，水平垂直居中
3. **自适应终端**：运行时获取终端尺寸，自动调整布局
4. **Box-drawing边框**：用Unicode box-drawing字符画边框和分隔线
5. **状态栏**：底部状态栏显示步数、推箱数、操作提示
6. **标题栏**：顶部标题栏显示游戏名和关卡编号

## 小Phrase划分

- Phrase 1: 终端尺寸检测与全屏缓冲区
- Phrase 2: 双宽地图渲染器
- Phrase 3: 全屏布局引擎（边框、面板、居中）
- Phrase 4: GameLoop适配与综合调试
