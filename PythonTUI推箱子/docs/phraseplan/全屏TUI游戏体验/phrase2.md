# Phrase 2: 双宽地图渲染器

## 状态: ✅ 已完成

## 目标

重写地图渲染，每个地图格子用2个终端列宽渲染，使用全角Unicode字符，让地图视觉上更方正清晰。

## 设计

### 双宽渲染方案

每个地图格子占2列宽1行高，使用全角/双宽字符：

| TileType | 双宽字符 | 颜色 |
|----------|----------|------|
| WALL     | ██       | 灰色背景 |
| FLOOR    | ··       | 暗灰 |
| TARGET   | ○○       | 红色 |
| BOX      | □□       | 棕色 |
| BOX_ON_TARGET | ★★ | 绿色 |
| PLAYER   | ♦♦       | 蓝色高亮 |
| PLAYER_ON_TARGET | ♦♦ | 蓝色高亮 |

### TileRendererV2

- 每种TileType渲染为2字符宽的字符串
- 支持颜色方案
- 支持纯文本降级

### 文件结构

```
src/engine/
  tile_renderer_v2.py   # TileRendererV2, 双宽渲染配置
```
