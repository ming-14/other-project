# Phrase 3: 全屏布局引擎

## 状态: ✅ 已完成

## 目标

实现全屏布局：标题栏、地图居中区域、状态栏，用box-drawing字符画边框。

## 设计

### LayoutEngine

- 根据终端尺寸和地图尺寸计算布局
- 布局区域：
  - 标题栏（1行）：游戏名 + 关卡编号
  - 地图区域（居中）：双宽渲染的地图
  - 状态栏（1行）：步数、推箱数、操作提示
- 地图区域用box-drawing边框包围
- 地图在可用区域内水平垂直居中

### Box-drawing字符

```
┌ ┬ ┐ │ ┴ └ ├ ┼ ┤ ─ ┬ ┴
```

### 渲染流程

1. 清空ScreenBuffer
2. 绘制标题栏
3. 计算地图居中位置
4. 绘制地图边框
5. 绘制地图内容
6. 绘制状态栏
7. diff输出到终端

### 文件结构

```
src/engine/
  layout_engine.py   # LayoutEngine, 布局计算与绘制
```
