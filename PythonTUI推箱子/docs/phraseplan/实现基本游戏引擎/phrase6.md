# Phrase 6: 游戏主循环集成

## 状态: ✅ 已完成

## 目标

将所有引擎集成，实现游戏主循环，使推箱子游戏完整可玩。

## 设计

### GameLoop

- 主循环：输入 → 逻辑 → 渲染 → 等待
- 状态管理：PLAYING, WON, QUIT
- 关卡切换：当前关卡胜利后进入下一关
- 游戏信息显示：关卡编号、步数、推箱次数

### LevelData

- 内置至少3个经典关卡
- 关卡数据以字符串列表形式存储

### 文件结构

```
src/
  engine/
    game_loop.py    # GameLoop, GameState
  data/
    levels.py       # LevelData, 内置关卡
  main.py           # 入口
```

### 主循环流程

1. 初始化：加载关卡、清屏、首次渲染
2. 循环：
   a. 读取输入（非阻塞）
   b. 根据输入动作执行逻辑
   c. 检查胜利条件
   d. 渲染屏幕
   e. 短暂等待（控制帧率）
3. 胜利：显示胜利信息，等待按键进入下一关
4. 所有关卡通关：显示通关信息

## 验收标准

- [ ] 游戏可以启动并显示关卡

- [ ] 可以切换到下一关

- [ ] Q键退出游戏
- [ ] 步数和推箱次数正确统计
- [ ] 至少3个内置关卡
