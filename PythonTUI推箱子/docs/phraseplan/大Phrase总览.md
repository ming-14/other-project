# 推箱子游戏 - 大Phrase总览

## 游戏概述

经典推箱子（Sokoban）命令行版本。玩家在二维网格地图中控制角色，将所有箱子推到目标点上即可过关。

## 大Phrase划分

### 大Phrase 1: 实现基本游戏引擎

**目标**: 从零搭建可玩的最小推箱子游戏，包含地图、移动、碰撞、胜利判定、渲染、输入。

小Phrase:
- Phrase 1: 核心数据结构与地图引擎
- Phrase 2: 移动与碰撞引擎
- Phrase 3: 胜利判定引擎
- Phrase 4: 终端渲染引擎
- Phrase 5: 输入处理引擎
- Phrase 6: 游戏主循环集成

**完成标准**: 玩家可以通过键盘操控角色推箱子，将所有箱子推到目标点后显示胜利，至少内置3个关卡。

### 大Phrase 2: 全屏TUI游戏体验（已完成）

**目标**: 全屏终端渲染、双宽地图、布局引擎、状态栏。

小Phrase:
- Phrase 1: 终端尺寸检测与全屏缓冲区
- Phrase 2: 双宽地图渲染器
- Phrase 3: 全屏布局引擎
- Phrase 4: GameLoop适配与综合调试

**完成标准**: ✅ 全屏TUI游戏可玩，110个单元测试通过，3关全部通关。

### 大Phrase 3: 高级功能与体验优化（进行中）

**目标**: 修复性能问题、支持标准关卡格式、自动求解、存档系统、完善游戏流程。

小Phrase:
- Phrase 1: ScreenBuffer差异更新修复与技术债清理
- Phrase 2: 标准Sokoban关卡加载器与关卡选择
- Phrase 3: 自动求解器（BFS）
- Phrase 4: 存档系统与游戏流程完善

### 大Phase 4: TUI像素引擎与贴图渲染（已完成）

**目标**: 构建独立的TUI像素渲染引擎（半块方格▀技术），支持8×8贴图，替换sokoban字符渲染为像素画。

小Phase:
- Phase 1: 颜色系统与像素缓冲区
- Phase 2: 贴图系统与半块渲染器
- Phase 3: 推箱子8×8贴图定义与验证
- Phase 4: sokoban集成——LayoutEngine改用像素引擎

**完成标准**: ✅ 游戏全屏TUI可玩，地图显示为8×8像素贴图，116个单元测试通过，3关全部渲染成功。

## 架构原则

- 干净架构，底层引擎与高层逻辑分离
- 引擎层必须留debug接口
- 不使用Textual框架
- 底层→高层开发顺序
