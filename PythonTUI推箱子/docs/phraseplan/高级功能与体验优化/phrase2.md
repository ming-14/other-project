# Phrase 2: 标准Sokoban关卡加载器与关卡选择

## 状态: 待执行

## 目标
支持加载标准Sokoban格式文件（.sok/.txt），内置更多经典关卡，实现关卡选择界面。

## 背景
当前只有3个硬编码的简单关卡，玩家通关后游戏就结束了。标准Sokoban社区有数千个关卡集，支持加载外部文件可以极大丰富游戏内容。

## 具体任务

### 1. 标准Sokoban格式解析器
- 支持标准Sokoban文本格式（#墙 $箱 .目标 @玩家 +玩家在目标 *箱在目标 -空格/外部）
- 支持一个文件包含多个关卡（空行分隔）
- 支持注释行（;或//开头）
- 关卡集数据结构：LevelSet（名称、关卡列表、元数据）

### 2. 关卡加载器
- 从内置数据加载
- 从外部文件加载（指定路径）
- 从data/levels/目录批量加载
- 关卡验证（箱子数>=目标数、有玩家、可到达性检查）

### 3. 内置更多关卡
- 从Microban（David Skinner设计，155个经典小关卡）中选取10-20个
- 按难度排序
- 确保每个关卡可解（可用BFS验证，但Phrase2先手动验证）

### 4. 关卡选择界面
- 全屏TUI关卡列表
- 显示关卡编号、名称、难度、完成状态
- 方向键/WASD选择，Enter确认
- Esc返回
