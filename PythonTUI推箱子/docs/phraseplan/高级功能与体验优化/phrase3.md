# Phrase 3: 自动求解器（BFS）

## 状态: 待执行

## 目标
实现BFS自动求解器，用于关卡验证和玩家提示功能。

## 背景
推箱子是NP-hard问题，但对于小关卡（<50格），BFS可以在合理时间内找到最优解。自动求解器有两个用途：
1. 开发时验证关卡可解性
2. 游戏中给玩家提示下一步走法

## 具体任务

### 1. BFS求解引擎
- 状态表示：玩家位置+箱子位置集合（frozenset）
- 状态空间搜索：BFS保证最短步数解
- 剪枝优化：
  a. 死锁检测（箱子推到角落且不在目标上）
  b. 已访问状态去重（set of (player_pos, frozenset(boxes))）
  c. 可选：只搜索push-optimal解（只考虑推箱次数，忽略走步）
- 超时机制：搜索超过N秒自动停止
- Debug接口：导出搜索统计（访问状态数、搜索时间、解长度）

### 2. 求解器集成
- 引擎层：SolverEngine，输入GameMap，输出解（方向列表）或None
- 游戏循环：按H键请求提示，显示下一步方向
- 关卡加载时可选验证可解性

### 3. 死锁检测
- 简单死锁：箱子在角落（两面墙）且不在目标上
- 冻结死锁：箱子被墙/其他冻结箱子包围，无法移动且不在目标上
- 死锁表：预计算每个位置的简单死锁标记

## 验证标准
- [ ] BFS能求解内置所有关卡
- [ ] 死锁检测正确识别角落死锁
- [ ] 提示功能在游戏中可用
- [ ] 求解器有debug接口
- [ ] 单元测试覆盖
