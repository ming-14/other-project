# Phrase 4: 存档系统与游戏流程完善

## 状态: 待执行

## 目标
实现存档/读档系统，完善游戏流程状态机（主菜单→选关→游戏→胜利），增加过关统计。

## 具体任务

### 1. 存档系统
- 存档数据：当前关卡、步数、推箱数、玩家位置、箱子位置、undo栈
- 存档格式：JSON
- 存档位置：用户目录下 .sokoban/saves/
- 操作：F5保存、F9读取、自动存档（每步后）

### 2. 游戏流程状态机
- 状态：MAIN_MENU → LEVEL_SELECT → PLAYING → WON → (next or ALL_CLEAR)
- 主菜单：新游戏、继续、选关、退出
- 过关动画：闪烁/高亮效果
- 全通关画面优化

### 3. 过关统计
- 记录每关最佳步数、最佳推箱数
- 统计数据持久化（JSON，.sokoban/stats/）
- 过关时显示与最佳记录对比
