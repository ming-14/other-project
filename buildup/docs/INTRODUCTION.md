# 力量训练指南 - 项目介绍

## 项目概述

**力量训练指南** 是一个专为健身爱好者设计的现代化、交互式的力量训练辅助Web应用。该项目采用纯前端技术栈（HTML5、CSS3、JavaScript），提供完整的训练计划管理、动作指导、进度跟踪和视频演示功能。

## 核心功能

### 训练计划管理
- **多种训练计划**：提供常规训练、跑前热身、跑后训练、膝关节保护等不同类别的训练计划
- **智能筛选**：按类别、难度、时长筛选训练计划
- **计划详情**：查看每个训练计划的详细结构、动作组成和预计时长
- **一键开始**：选择计划后直接进入训练模式

### 交互式训练界面
- **实时倒计时**：支持时间型和次数型动作的倒计时显示
- **进度跟踪**：实时显示训练进度和当前环节
- **动作指导**：详细的动作说明、关键要领和常见错误提示
- **视频演示**：每个动作都配有标准演示视频
- **悬浮窗模式**：视频支持悬浮窗播放，可在训练时保持可见

### 智能训练控制
- **开始/暂停**：随时控制训练流程
- **上一组/下一组**：灵活调整训练进度
- **自动切换**：动作完成后自动进入休息或下一组
- **力竭模式**：支持力竭训练的特殊处理
- **进度保存**：实时保存训练进度

### 用户体验优化
- **响应式设计**：适配桌面端和移动端
- **深色/浅色主题**：支持主题切换，保护视力
- **动作库搜索**：快速查找特定动作
- **动作详情查看**：查看每个动作的详细说明和视频
- **错误处理**：完善的错误处理和用户提示

## 技术架构

### 前端技术栈
- **HTML5**：语义化标签，现代化结构
- **CSS3**：CSS变量、Flexbox、Grid布局、响应式设计
- **JavaScript (ES6+)**：模块化、面向对象编程
- **原生API**：Video API、LocalStorage、DOM操作

### 核心模块设计

#### 1. **TrainingController** (`training.js`)
训练流程控制的核心类，负责：
- 训练状态管理（开始、暂停、继续）
- 动作切换和倒计时控制
- 进度计算和更新
- 力竭模式处理
- 音频提示播放

#### 2. **VideoController** (`video.js`)
视频播放和控制的专业模块，提供：
- 视频加载和播放控制
- 悬浮窗模式切换
- 全屏播放支持
- 音量控制
- 错误处理和回退

#### 3. **ProgressManager** (`progress.js`)
训练进度管理模块，功能包括：
- 进度条实时更新
- 当前环节显示
- 总步数计算
- 进度百分比计算

#### 4. **UIManager** (`ui.js`)
用户界面管理模块，提供：
- 通知提示显示
- 确认对话框
- 帮助信息显示
- 错误信息展示

#### 5. **数据管理** (`exercises.js`, `trainingPlans.js`)
- 包含50+个标准训练动作的详细数据
- 多个训练计划配置
- 动作分类和筛选支持
- 视频路径管理

## 特色功能详解

### 1. **智能倒计时系统**
- 时间型动作：显示剩余秒数
- 次数型动作：显示剩余次数和预估时间
- 休息时间：自动计算和显示
- 力竭模式：特殊处理，等待用户手动切换

### 2. **视频悬浮窗**
- 可拖拽调整位置
- 可调整大小
- 保持在其他窗口上方
- 与主视频同步状态

### 3. **主题系统**
- 基于CSS变量的主题管理
- 支持深色/浅色模式切换
- 用户偏好本地存储
- 平滑过渡动画

### 4. **响应式布局**
- 桌面端：两栏布局（主内容+侧边栏）
- 移动端：自适应单栏布局
- 触摸友好的交互设计
- 适配不同屏幕尺寸

## 使用指南

### 快速开始
1. 打开 `index.html` 进入主页面

3. 点击"开始训练"进入训练页面
4. 按照指引完成训练

- **上一组/下一组**：手动调整进度

### 主题切换
点击右上角的/图标切换深色/浅色主题

### 动作库
在侧边栏搜索和查看所有动作的详细说明

## 开发建议

### 环境要求
- 现代浏览器（Chrome 80+、Firefox 75+、Safari 13+）
- 本地服务器（推荐使用Live Server或http-server）

### 部署方式
1. 直接上传到静态网站托管服务（GitHub Pages、Netlify、Vercel等）
2. 使用任何Web服务器（Nginx、Apache、IIS）
3. 本地文件系统直接打开（部分功能可能需要本地服务器）

### 扩展建议
1. **添加更多训练计划**：编辑 `data/trainingPlans.js`
2. **添加新动作**：编辑 `data/exercises.js`
3. **自定义样式**：修改CSS文件中的变量
4. **添加新功能**：遵循现有模块化架构
